# SJTU LIMO Lab

Homepage of the Lab for Imaging, Machine Learning and Optimization (LIMO) at the Institute of Natural Sciences, Shanghai Jiao Tong University.

**Website:** [https://limo-sjtu.github.io](https://limo-sjtu.github.io)

## Research Areas

- Mathematical Image Processing
- Medical Image Processing
- Machine Learning
- Optimization

## Lab

The lab is led by [Prof. Xiaoqun Zhang](https://math.sjtu.edu.cn/faculty/xqzhang/) and [Prof. Jingwei Liang](https://jliang993.github.io/) at the Institute of Natural Sciences, Shanghai Jiao Tong University.

## Website updates

Lab members can request profile, publication, news, and correction updates through the
[website update forms](https://github.com/limo-sjtu/limo-sjtu.github.io/issues/new/choose).
Repository write access is not required. See [CONTRIBUTING.md](CONTRIBUTING.md) for the member workflow and [update.md](update.md) for maintainer instructions.
